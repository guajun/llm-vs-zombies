# 项目准备与验证

日期：2026-09-18。

## 已准备

- 官方 AvZ 固定提交、2.9.2 发布包和注入器。
- 本机英文 1.0.0.1051 名称目录的游戏副本及文件 SHA-256。
- LLVM-MinGW 20260908，归档 SHA-256 与上游发布资产声明一致。
- 两仪参考存档和两份中文教程。
- Python 实验工具、C++ 记录器、HTML 复盘器和测试。

## 验证范围

1. 使用 LLVM-MinGW i686 / Clang 23.1.1 从固定 AvZ 源码编译记录 DLL；没有把未经匹配的预编译静态库混入。
2. **12 项 Python 单元测试通过**，覆盖实际数据管道、首个状态差异、跨片段时间重置、日志截断、序号丢失、哈希篡改、注入文本转义、覆盖保护、采集锁及附件哈希。
3. C++ 缓冲写入器独立运行，**3000 条 JSON 记录的序号、换行、引号和中文往返验证通过**，未加载游戏内存。DLL、测试程序、游戏 EXE 均核实为 PE i386。
4. 合成演示 `demo-review` 含 **124 条事件、121 个状态样本**，明确标为 synthetic；已在浏览器检查页面布局与时间线，到帧 300 能显示对应动作事件。
5. `doctor` 核实 7 个固定文件哈希及 AvZ 提交；游戏本体、参考存档、发布包与注入器均一致。

具体命令、测试输出及构建验证结果保存在 `work/`，演示记录保存在 `experiments/runs/`。首版构建含上游代码的符号比较等编译警告，未修改上游。
